# Design de teste - Tarefa 2

Projeto do 2º sprint do curso de QA: design de testes para o formulário **Adicionar carteira de motorista** do Urban Routes.

## Conteúdo

- `Design_de_teste_Tarefa_2.xlsx`: classes de equivalência e valores-limite para Nome, Sobrenome e Data de nascimento; casos de teste apenas para Nome.

O material documenta o design dos testes. A execução dos testes não faz parte desta tarefa.

## Fonte

Requisitos de compartilhamento de carros no Urban Routes, seção “O campo Adicionar carteira de motorista”, fornecidos para este projeto.
